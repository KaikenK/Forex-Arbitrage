# EOD data for the USD/INR basis path

Zero-KYC, zero-cost historical inputs. Drop the real CSVs here and point
`research/run_eod_basis.py` at them. The loader (`backend/core/data_sources/
eod_loader.py`) is column-name tolerant — NSE bhavcopy, CME settlement,
investing.com and yfinance exports all parse without editing headers.

`SAMPLE_*.csv` are synthetic (generated by `research/make_sample_eod.py`) so the
pipeline runs out of the box. **They are invented — replace them with real files
before quoting any number.**

## What auto-fetches vs what you must download

| Leg | Auto-fetch? | Why |
|---|---|---|
| **Spot** (`USDINR=X`) | ✅ `--use-yfinance` — free, no account | Yahoo carries it |
| **Onshore** NSE USD/INR future | ❌ manual CSV | NSE blocks scrapers; `jugaad-data` only does equity F&O |
| **Offshore** CME rupee future | ❌ manual CSV | not on Yahoo; CME real-time is paid |

Fastest real run = download **one** file (the onshore NSE future history) and let
yfinance supply spot:

```bash
pip install yfinance
python research/run_eod_basis.py --use-yfinance \
    --start 2025-06-01 --end 2026-08-29 \
    --onshore-csv data/eod/nse_usdinr_fut.csv
```

That gives a real **onshore-future vs spot** basis (the USD/INR forward premium and
its CIP deviations). Add `--offshore-csv` once you have CME data for the true
onshore↔offshore (NDF) number.

## Onshore — NSE currency-derivatives (USD/INR future)  ← use this

**nseindia.com → Market Data → Historical Data → Derivatives.** Set
Instrument `FUTCUR`, Underlying `USDINR`, a From/To range (1 year+), **GO**, wait
for the table to fill, then **Download (.csv)**. Works in a browser — scripts are
bot-blocked, so this is the reliable path.

The export has one row per *listed contract per day* (front month + far months),
with columns `TRADE DATE, INSTRUMENT, CONTRACTS, ..., CLOSE PRICE, DAILY
SETTLEMENT PRICE, OI, ...`. The loader handles this automatically:

- reads `DAILY SETTLEMENT PRICE` as the daily mark (falls back to `CLOSE PRICE`);
- parses the expiry from the `CONTRACTS` code (`USDINR 280926` → 2026-09-28);
- keeps only the **front-month** contract per trade date.

Save it as `data/eod/nse_usdinr_fut.csv` — no editing needed.

Do **not** use investing.com's "USD/INR" page — that is spot, not the future.

## Offshore — CME Indian Rupee future (proxy for NDF)  ← the robust basis

This is the leg that makes `onshore_offshore` the trustworthy number (the carry
adjustment cancels, unlike the spot pair). Get daily **settlement** prices for the
CME Indian Rupee/USD future (contract 6R, or E-micro MIR):

**There is no scriptable free source** — every automated endpoint (Nasdaq Data Link
`CHRIS/*` is discontinued; investing.com / barchart / CME are Cloudflare/Incapsula
bot-blocked). Download by hand in a browser:

| Source | How | Cost |
|---|---|---|
| **investing.com → "INR Futures" → Historical Data** | pick a date range, **Download Data** (needs a free login). This is the CME SIR/6R contract. | free |
| Barchart.com → "Indian Rupee Futures" → front-month contract → Historical Data → Download | free login | free |
| TradingView chart `CME:SIR1!` → export | needs a paid plan for CSV export | — |
| Dukascopy historical-data export, instrument `USD/INR` | no login; browser export tool. This is an OTC/CFD quote — use it as the **offshore proxy** if the CME contract is unavailable. | free |

Save whatever you get as `data/eod/cme_inr_fut.csv`. The loader now rejects an HTML
error page with a clear message instead of a stack trace.

**Quote convention.** CME/SGX rupee futures are quoted **USD per INR** (≈ 0.0117),
not USD/INR. The loader auto-detects the common cases (median < 1 → reciprocal;
median > 1000 → ÷100). Override with
`--offshore-convention {USDINR,INRUSD,USDINR_x100,INRUSD_x10000}`.

- **investing.com "Indian Rupee Futures"** exports quote `1/USDINR × 10000` (≈ 104–117).
  This range overlaps a genuine USD/INR near 100, so `auto` will **not** catch it —
  pass `--offshore-convention INRUSD_x10000` explicitly (USD/INR = 10000 / quote).
  A real run with this file gives an `onshore_offshore` basis of mean ≈ −7 pips,
  |mean| ≈ 15, p90 ≈ 32 over 2025-08 → 2026-08.

Save as `data/eod/cme_inr_fut.csv` and run:

```bash
python research/run_eod_basis.py --use-yfinance \
    --start 2025-06-01 --end 2026-08-29 \
    --onshore-csv data/eod/nse_usdinr_fut.csv \
    --offshore-csv data/eod/cme_inr_fut.csv \
    --run-id real
```

## Spot / reference

| Source | How | Cost |
|---|---|---|
| `yfinance` ticker **`USDINR=X`** | `--use-yfinance` | free |
| RBI reference rate | rbi.org.in → "Reference Rate Archive" CSV | free |
| FBIL | fbil.org.in daily USD/INR | free |

## Run

```bash
python research/make_sample_eod.py          # (re)create the SAMPLE files
python research/run_eod_basis.py             # sample run
python research/run_eod_basis.py \
    --onshore-csv data/eod/nse_usdinr_fut.csv \
    --offshore-csv data/eod/cme_inr_fut.csv \
    --spot-csv data/eod/rbi_reference.csv \
    --carry 0.019 --run-id 2026H1
# or let yfinance supply offshore + spot:
python research/run_eod_basis.py --use-yfinance --start 2025-01-01 --end 2026-08-28 \
    --onshore-csv data/eod/nse_usdinr_fut.csv
python research/make_figures.py              # writes fig_eod_basis.png
```

Output: `research/results/eod/<run-id>/{basis_eod.jsonl, summary.json}`.
The `onshore_offshore` pair is the robust headline (carry cancels); pairs
involving `spot` are only meaningful once `--carry` is calibrated (SPEC §3.3).
